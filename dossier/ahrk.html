02 · Question

Where does a compact room lose its flexibility?

Compact premium hotel rooms are asked to host arrival, work, dining, rest and wellness in one footprint. Their furniture is fixed in layout but loose in objects, so every housekeeping reset becomes a judgement call. Working from a real built room as a private reference, the project mapped where the room loses flexibility: the free long wall already carried a desk, a chair, a round table and an armchair, while luggage landed on the bed or in the entry pinch. The question became whether one wall could hold all of those states — and return every module to a single home line that staff can read at a glance.

~4 → 1 + 1

Loose objects on the free wall → one wall system + one tuck-under stool

03 · Mechanism

Six named modes. Two physical states. One hinge that carries the load.

Pick a mode: it snaps to its physical family, the wall crossfades, and the surface folds about its pivot. At 90° the lock seats and the load runs to the wall — never through the spine.

06 · Decisions

What was set aside, and why.

Rail architectureSTEP-02 · 26–27 Jun 2026

Set aside. A · Single continuous rail

Structurally dishonest: forces bench + surface load onto the extrusion.

Set aside. B · Distributed local anchors

Loses the system: modules read as separate fittings, not a family.

Selected

Selected. C · Hybrid spine + anchor nodes

Spine carries identity, routing and low load; discrete anchors take high load to structure.

Fold-down mechanismSTEP-05

Set aside. A · Drop-leaf hinge + locking stay

Reads domestic / hospital; visible stay; rigidity depends on a thin stay.

Selected

Selected. B · Concealed pivot bracket + damper stay

Hidden hardware, damped both ways, bracket sized for the moment; separate over-centre lock.

Set aside. C · Side-arm parallelogram

Arms project into the side clearance, visually busy; eats Zone B width.

Set aside. D · Sliding pull-out cassette

Needs a ≥450-deep wall cassette; defeats the slim retrofit.

Luggage benchSTEP-06

Selected

Selected. A · Fixed floor-supported + wall tie

Weight to the floor; the tie only stops tipping. Doubles as a seat.

Set aside. B · Fold-up luggage rack

Reads budget hotel; cannot be a seat; webbing sags.

Set aside. C · Wall-hung bench on hard anchors

80–120 kg cantilever into an uncertain retrofit substrate.

Variant

Kept as a variant. D · Bench in a shallow joinery carcass

Kept as a premium variant, not the base: closer to fitted-furniture renovation.

Mode and module countSTEP-01

Set aside. Six distinct mechanisms

Work and Dining drive nearly identical mechanics — “don’t fake a sixth mode”.

Selected

Selected. One surface, two presets

Six named modes reduce honestly to two physical families.

Set aside. A sixth module

Coat hook, charging, tray, mirror would sprawl the family.

Selected

Selected. Five modules + rail accessories

Every gap resolves as a rail accessory — one rail standard, many attachments.
