AHRK / Product-Spatial Retrofit System

One adaptive wall, six room states.

AHRK is a retrofit product-spatial system that helps a compact hotel room shift between work, rest, luggage, dining, wellness, and housekeeping-reset states through one adaptive wall — without a full room redesign.

The room plan used in this project is a redrawn spatial abstraction based on reference topology only. It is not a reproduction of an original drawing — no dimensions, title block, or construction details from any source drawing appear here or elsewhere in this project.

This case study documents design reasoning and mechanism validation. It does not report measured ROI, revenue impact, certified durability or fire ratings, user research findings, operator interviews, or area-saving statistics. Anchor strategy is a design intent to be verified per wall condition, not a certified or universal installation method.
