01 — The project

Relief ring

The relief works like a setting without stones: small domed bosses run around one edge and catch the light in sequence as the piece turns.

Sizes run from a Ø50 mm bangle down to a Ø16.7 mm ring, measured on the STL files. The renders show the pieces in polished gold; the print files themselves are material-neutral.
