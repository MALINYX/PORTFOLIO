02 — The design challenge

Seven exceptions. Nobody owned them.

In the reconstructed record, corrective action stayed open for 11 days, the owner field was unassigned, a monitoring dependency was dead and a shift ran an undocumented workaround. The investigation argues the cause was not a missed alert or a software bug.

Decision 01

Reconstruct before you explain

Incident reconstruction, evidence clustered into a six-category taxonomy, a recurrence map and a failure-chain map.

Designed

Decision 02

One colour, one meaning

Violet for governance, red for failure, amber for warning: colour encodes system meaning, never decoration.

Designed

Decision 03

Make the failure spatial

A static evidence chamber, built from a script in Blender, gives the record a room you can stand in.
